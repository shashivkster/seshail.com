# Employer and institution logos

Each cell on the Affiliations section shows a typeset organisation name by
default. That treatment is complete on its own — nothing looks broken if this
folder stays empty.

To use real logos instead, drop files here with these exact names:

    bdo.svg       BDO
    pwc.svg       PricewaterhouseCoopers
    syntel.svg    Syntel
    iitkgp.svg    IIT Kharagpur / VGSOM
    fcrit.svg     Fr. C. Rodrigues Institute of Technology

The page swaps typography for the image automatically when a file loads, and
falls back silently when one is missing. Both .svg and .png work — if you use
PNG, supply it at roughly 400px wide on a transparent background.

Notes on sourcing:

- Take logos from the organisation's own brand or media page where one exists.
  BDO and PwC both publish brand guidelines governing third-party use.
- Logos are rendered greyscale at reduced opacity so they sit inside the site
  palette rather than competing with it.
- Displaying a former employer's logo to state factual employment history is
  ordinary practice, but the marks belong to their owners and some brand
  guidelines restrict use by individuals. If in doubt, the typographic
  treatment carries no such constraint — which is why it is the default.
